读数据、先看一眼

读 parquet / csvdf = pd.read_parquet('x.parquet')
df = pd.read_csv('x.csv')

行数、列数df.shape

每列类型、空值df.info()

每列空值个数df.isna().sum()
某列有哪些值、各多少df['col'].value_counts()
不同值个数df['col'].nunique()

选行、选列

取一列（Series）df['a'] 或 df.a
取几列（DataFrame）df[['a', 'b']]
按条件筛行df[df.a > 0]
多个条件（要加括号）df[(df.a > 0) & (df.b == 'x')]；或用 |
在一组值里df[df.id.isin([1, 2, 3])]
按索引取行df.loc[idx]；多层索引 df.loc[(0, 12)]
按位置取行df.iloc[0]、df.iloc[:5]
按索引取行并选列df.loc[df.a > 0, 'b']
丢掉空值行df.dropna()；只看某列 df.dropna(subset=['a'])
去重df.drop_duplicates(['k1', 'k2'])

加列、改值

加一列df['r2'] = df.r ** 2
多列算出一列df['sp'] = (df.ask - df.bid) / df.mid
按条件赋值df['y'] = np.where(df.a > 0, 1, 0)
填空值df['a'].fillna(0)
改类型df['a'].astype('float32')
改列名df.rename(columns={'old': 'new'})
一次加多列（链式）df.assign(r2=df.r**2, seg=df.sec // 60)
对数、裁剪np.log(x + 1e-10)、x.clip(lower=0)

分组汇总 groupby

按两列分组求和（结果每组一行）df.groupby(['stock_id', 'time_id']).r2.sum()
一次算多个统计量g.r.agg(['mean', 'std', 'count'])
不同列不同统计量、并命名g.agg(rv=('r2', 'sum'), sp=('sp', 'mean'))
组内统计放回原表（行数不变）df['m'] = df.groupby('t').x.transform('mean')
组内减均值（去均值）df.x - df.groupby('t').x.transform('mean')
只对部分行分组df[df.sec >= 300].groupby(k).r2.sum()
组内自定义函数g.apply(lambda d: (d.r ** 2).sum())（慢，能用 agg 就用 agg）
组号（每组一个整数）df.groupby(k).ngroup()
分组后还原成普通列.reset_index()

多层索引 MultiIndex

取某一层的值s.index.get_level_values('time_id')

合并、透视

按键合并（像 SQL join）a.merge(b, on=['k1', 'k2'], how='left')
上下拼接pd.concat([a, b])；左右拼 axis=1
长表变宽表df.pivot_table(index='time', columns='stock', values='x', aggfunc='mean')
宽表变长表df.melt(id_vars='time', var_name='stock', value_name='x')

排序、排名、分位

排序df.sort_values(['a', 'b'], ascending=[True, False])

相关系数df[['a', 'b']].corr()；秩相关 method='spearman'

时间序列：shift、diff、rolling

上一行的值（组内）df.groupby('id').x.shift(1)
和上一行的差df.groupby('id').x.diff()
对数收益np.log(p).groupby(df.id).diff()

转成日期、取年份pd.to_datetime(df.t).dt.year

常见坑

多条件忘了加括号df[(a > 0) & (b < 1)]，不是 a > 0 & b < 1
改切片报 SettingWithCopyWarning先 .copy() 再改
agg 还是 transform要每组一行用 agg；要和原表对齐用 transform
log(0) 变成 -infnp.log(x + 1e-10)
随机切验证集造成泄漏同一时刻 / 同一组的数据要整组放进同一折
交错了量（波动率 vs 方差）交之前看一眼数量级
